<p align="center">
  A simple Notepad++ plugin that adds a second vertical scrollbar with mirrored line numbers and markers.<br>
</p>

</p>
  <img width="700" height="1" src="https://via.placeholder.com/700x1/262626/262626">
</p>

### ✨ Features :

| Feature | Description |
|---|---|
| ↕️ Dual vertical scrollbars | Adds a second vertical scrollbar to the left while keeping the native scrollbar on the right. |
| 🪞 Mirrored margins | Displays line numbers, bookmarks, fold markers and change-history markers on both sides. |
| 🔄 Synchronized scrolling | Both scrollbars follow the current document position. |
| ✂️ Split-view support | Works correctly with Notepad++ split views. |
| 🎨 Native appearance | Matches the current Notepad++ interface and scrollbar styling. |
| 🖱️ Mouse support | Supports scrolling and interactions from either side of the editor. |

### ✅ Manual Installation :

| Step | Action |
|:---:|---|
| 1️⃣ | Download the latest release [here](../../releases/latest) |
| 2️⃣ | Create a folder named `DualScrollbars` inside `C:\Program Files\Notepad++\plugins\` |
| 3️⃣ | Extract the archive and copy `DualScrollbars.dll` into the `DualScrollbars` folder |
| 4️⃣ | Restart Notepad++, then enable the plugin from `Plugins > Dual Scrollbars > Displays a double scrollbar` |

<br><ins>NOTE</ins> : The plugin is currently available through manual installation only.<br>
A [request](https://github.com/notepad-plus-plus/nppPluginList/pull/1148) is submitted for inclusion in the official Notepad++ Plugins Admin list.
